# ناسخ شامل (Universal Copier)

تطبيق Android لنسخ النصوص من واجهات التطبيقات ومن محتوى الشاشة عبر OCR أوفلاين، مع زر عائم، حافظة سريعة، وسجل/ذاكرة قوية.

- **Package:** `com.yahya.universalcopy`
- **Version:** 1.1 (`versionCode 2`)
- **Min SDK:** 24 (Android 7.0)
- **Target/Compile SDK:** 34
- **Language:** Java 17, AndroidX, ViewBinding

## الميزات

- **نسخ نصوص الواجهة (UI/Accessibility):** استخراج النصوص الظاهرة من عناصر الواجهة عبر خدمة إمكانية الوصول (يشمل العربية وباقي اللغات التي تعرضها التطبيقات كنصوص قابلة للوصول).
- **مسح الشاشة OCR أوفلاين (ML Kit):** التقاط الشاشة ثم التعرف على النص محليًا حسب الوضع:
  - عام/لاتيني (Latin)
  - صيني (Chinese)
  - كوري (Korean)
  - ياباني (Japanese)
  - هندي Devanagari
- **زر عائم سريع:** نسخ الواجهة، OCR بالوضع الحالي، الحافظة السريعة، السجل، إغلاق.
- **مربع إعدادات سريعة (Quick Settings Tile):** لتشغيل/استدعاء الزر العائم بسرعة.
- **حافظة سريعة:** عرض نص الحافظة الحالي، نسخه/حفظه، والوصول السريع لآخر العناصر.
- **ذاكرة/سجل قوي:** حفظ تلقائي/يدوي، بحث، تثبيت، حذف، منع التكرار، حد أقصى قابل للضبط.
- **إجراءات تلقائية قابلة للضبط:** نسخ تلقائي، حفظ تلقائي، فتح شاشة النتيجة.
- **اختصارات إعدادات نظامية:** إمكانية الوصول، الظهور فوق التطبيقات، الإشعارات، تحسين البطارية.

## ملاحظات وحدود

- **العربية في OCR:** وحدات ML Kit المضافة لا تتضمن مخصصًا للنص العربي (Arabic script). يمكن غالبًا نسخ العربية من التطبيقات كنص واجهة عبر وضع **ناسخ عادي (UI)**. قد ينجح التعرف الجزئي في بعض الحالات لكن بدون ضمان.
- **التطبيقات المحمية/المحتوى غير النصي:** بعض التطبيقات تمنع الوصول للنصوص (FLAG_SECURE/حماية) أو تعرض النص داخل صور/رسوميات؛ في هذه الحالات جرّب OCR.
- **دقة OCR:** تعتمد على وضوح الشاشة/الصورة والخط وحجم النص واختيار الوضع الصحيح.
- **لا يوجد iOS:** المشروع Android فقط.
- التطبيق يحتاج أذونات حساسة (إمكانية الوصول، الظهور فوق التطبيقات، التقاط الشاشة) ليعمل؛ لا يُنصح باستخدامه إلا عند الحاجة وبمعرفة المستخدم.

## الأذونات والسلوك

يعلن `AndroidManifest.xml` عن:
- `BIND_ACCESSIBILITY_SERVICE` (خدمة `UniversalCopyAccessibilityService`) لقراءة عناصر الواجهة عند طلب المستخدم.
- `SYSTEM_ALERT_WINDOW` لعرض الزر العائم (`OverlayService`).
- `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` (overlay) + `FOREGROUND_SERVICE_MEDIA_PROJECTION` (التقاط الشاشة/OCR).
- `POST_NOTIFICATIONS` (Android 13+) لإشعارات الخدمات الأمامية.

سلوك الخصوصية في الكود الحالي: النسخ/OCR يعمل عند طلب المستخدم (زر/إجراء)، المعالجة تتم على الجهاز (ML Kit bundled/on-device)، ويتم حفظ النص في السجل المحلي فقط عند تفعيل الحفظ التلقائي أو الحفظ اليدوي.

## البناء والتشغيل

### عبر Android Studio (مُوصى به)
1. افتح المجلد `UniversalCopier/` كمشروع.
2. تأكد من تثبيت **Android SDK 34** و**JDK 17** (Gradle JDK = 17).
3. اترك Android Studio يقوم بمزامنة Gradle (Sync) وتحميل التبعيات.
4. شغّل على جهاز حقيقي (أفضل لاختبار Accessibility/Overlay/MediaProjection) أو محاكي مدعوم.
5. لبناء APK: `Build > Build Bundle(s) / APK(s) > Build APK(s)` أو `./gradlew assembleDebug` إذا كان Gradle Wrapper متوفرًا.

### ملاحظات حول Gradle Wrapper
هذا المشروع لا يتضمن ملفات `gradlew`/`gradle-wrapper.jar` حاليًا. إذا لزم البناء من سطر الأوامر:
- استخدم Android Studio لتوليد/إدارة Gradle، أو
- ثبّت Gradle متوافقًا مع **AGP 8.2.2** على جهازك ثم نفّذ أوامر البناء من جذر المشروع.

## طريقة الاستخدام

1. افتح التطبيق وفعّل:
   - **خدمة إمكانية الوصول** (لنسخ نصوص الواجهة)
   - **إذن الظهور فوق التطبيقات** (للزر العائم)
   - **الإشعارات** (Android 13+، لخدمات foreground)
   - (اختياري) استثناء/تجاهل تحسين البطارية للاستجابة الأسرع
2. اختر **الوضع** (UI أو أحد أوضاع OCR).
3. شغّل **الزر العائم** أو استخدم **مربع الإعدادات السريعة**.
4. من الزر العائم:
   - **نسخ الواجهة**: يقرأ النصوص من الشاشة الحالية عبر Accessibility.
   - **مسح OCR**: يطلب إذن التقاط الشاشة ثم يستخرج النص حسب الوضع.
   - **الحافظة السريعة / السجل**: وصول فوري للعناصر المنسوخة.
5. اضبط السلوك (نسخ/حفظ تلقائي، فتح النتيجة، حد السجل) من **الإعدادات**.

## اختبار موصى به على جهاز حقيقي

- تفعيل/تعطيل Accessibility والتحقق من استخراج نصوص عربية/متعددة اللغات من تطبيقات مختلفة.
- ظهور الزر العائم فوق التطبيقات وسحبه/فتح القائمة.
- التقاط الشاشة + OCR لكل وضع (لاتيني/صيني/كوري/ياباني/Devanagari) مع صور/شاشات واضحة.
- الإشعارات والخدمات الأمامية على إصدارات Android المختلفة.
- الحافظة السريعة، الحفظ/التثبيت/الحذف/البحث/منع التكرار وحد السجل.
- سلوك التطبيقات المحمية وطلبات الأذونات.

## هيكل المشروع (ملخص)

- `app/src/main/java/com/yahya/universalcopy/` — الأنشطة والخدمات والمنطق (Accessibility, Overlay, MediaProjection/OCR, History/Prefs)
- `app/src/main/res/layout/` — واجهات التطبيق والعنصر العائم والسجل

- `app/src/main/res/values/` — نصوص وثيمات
