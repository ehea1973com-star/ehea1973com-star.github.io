دخول خاص

هذه الصفحة خاصة بمالك الموقع. سجّل الدخول بحساب المالك لعرض الإحصائيات ورفع التطبيقات.

العودة للموقع

بعد تسجيل الدخول بحساب المالك ستظهر الإحصائيات ونموذج رفع التطبيقات مع حقل GitHub Token (زر إظهار/إخفاء التوكن وحفظ تلقائي على هذا الجهاز) لرفع أي تطبيق ولقطات شاشة.

لوحة المطور

رفع تطبيق من الهاتف

اختر ملف APK، أدخل بيانات التطبيق، ثم ارفعه مباشرة إلى مستودع الموقع. سيظهر التطبيق في الصفحة الرئيسية بعد اكتمال نشر GitHub Pages.

استخدم GitHub Token بصلاحية Contents: Read and write على مستودع الموقع فقط. لا تشارك التوكن مع أي شخص، ويمكنك إلغاؤه من GitHub في أي وقت.
يُحفظ تلقائيًا على هذا الجهاز بعد اللصق. أنشئ توكنًا من GitHub Fine-grained tokens للمستودع ehea1973com-star.github.io بصلاحية Contents: Read and write فقط.
الحد الحالي 25 MB. للملفات الأكبر استخدم GitHub Releases.
صورة مربعة PNG أو SVG. إن لم تختر أيقونة، تُستخدم أيقونة عامة.
حتى 3 صور، سيتم تحويلها تلقائيًا إلى 720×1648. تظهر داخل نافذة تفاصيل التطبيق (قد تحتاج دقائق للنشر).
بعد لصق التوكن يُحفظ تلقائيًا في متصفح هذا الجهاز ليُستخدم لاحقًا (لوحة المالك ورفع لقطات الشاشة).
إلغاء

ماذا يحدث بعد الرفع؟

  1. يُرفع APK إلى مجلد apps/ والأيقونة إلى assets/uploads/.
  2. تُرفع لقطات الشاشة إلى assets/uploads/screens/ وتظهر في نافذة التفاصيل.
  3. تُضاف بيانات التطبيق والقسم إلى apps/manifest.json.
  4. تُحدّث بصمة SHA-256 في apps/SHA256SUMS.txt.
  5. يظهر التطبيق تلقائيًا في الصفحة الرئيسية بعد نشر GitHub Pages.
