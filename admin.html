رفع تطبيق من الهاتف

اختر ملف APK، أدخل بيانات التطبيق، ثم ارفعه مباشرة إلى مستودع الموقع. سيظهر التطبيق في الصفحة الرئيسية بعد اكتمال نشر GitHub Pages.

استخدم GitHub Token بصلاحية Contents: Read and write على مستودع الموقع فقط. لا تشارك التوكن مع أي شخص، ويمكنك إلغاؤه من GitHub في أي وقت.
أنشئ توكنًا من GitHub Fine-grained tokens واختر المستودع والصلاحية المذكورة أعلاه.
الحد الحالي 25 MB. للملفات الأكبر استخدم GitHub Releases.
صورة مربعة PNG أو SVG. إن لم تختر أيقونة، تُستخدم أيقونة عامة.
إلغاء

ماذا يحدث بعد الرفع؟

  1. يُرفع APK إلى مجلد apps/ والأيقونة إلى assets/uploads/.
  2. تُضاف بيانات التطبيق إلى apps/manifest.json.
  3. تُحدّث بصمة SHA-256 في apps/SHA256SUMS.txt.
  4. يظهر التطبيق تلقائيًا في الصفحة الرئيسية بعد نشر GitHub Pages.
