# Yahya Tech — الموقع الرسمي

الموقع الرسمي ليحيى الحمزة — Yahya Tech، منشور على GitHub Pages:

`https://ehea1973com-star.github.io/`

## المحتويات

- `index.html`: الصفحة الرئيسية، بطاقات التطبيقات وروابط التحميل.
- `404.html`: صفحة الخطأ.
- `assets/style.css`: تنسيق الموقع الكامل والواجهة المتجاوبة.
- `assets/script.js`: السنة، النسخ، شريط التنقل، وتأثيرات الظهور.
- `assets/logo.svg` و`assets/icons/`: شعار الموقع وأيقونات التطبيقات.
- `apps/`: ملفات APK ووحدة Magisk وملف بصمات `SHA256SUMS.txt`.

## التطبيقات المنشورة

- Smart Phone Detective v1.3.0
- نور الفجر v1.3.1
- Yahya Manager 2 v2.0.0
- Yahya RepairLive v1.6.1
- Yahya Shield v2.0
- Yahya Account Help v2.0
- Yahya Games Topup v2.0
- Yahya System Module v2.0 (Magisk)

## ملاحظات

- لا تُرفع ملفات keystore أو كلمات المرور إلى المستودع.
- حد GitHub لملف واحد هو 100 MB.
- التطبيقات الثلاثة الجديدة موقعة بنفس التوقيع، ورقم `versionCode` الحالي هو `2`؛ يجب رفعه في التحديث القادم.
- وحدة Magisk مخصصة للأجهزة التي تدعم Magisk أو ROM مخصصًا.
