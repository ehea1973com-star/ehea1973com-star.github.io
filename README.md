# Yahya Tech — الموقع الرسمي

الموقع الرسمي ليحيى الحمزة — Yahya Tech، منشور على GitHub Pages:

`https://ehea1973com-star.github.io/`

## المحتويات

- `index.html`: الصفحة الرئيسية، بطاقات التطبيقات وروابط التحميل.
- `admin.html`: لوحة رفع التطبيقات من الهاتف.
- `404.html`: صفحة الخطأ.
- `assets/style.css`: تنسيق الموقع الكامل والواجهة المتجاوبة.
- `assets/admin.css` و`assets/admin.js`: تنسيق ووظائف لوحة الرفع.
- `assets/script.js`: البحث والتصفية، نافذة تفاصيل التطبيق، المشاركة، الرابط العميق، وتأثيرات الظهور.
- `assets/theme.js`: الوضع الليلي/النهاري مع حفظ الاختيار في المتصفح.
- `assets/audio.js`: موسيقى هادئة مولّدة داخل المتصفح تتغيّر كل دقيقة، وأصوات الأزرار.
- `assets/logo.svg` و`assets/icons/`: شعار الموقع وأيقونات التطبيقات.
- `assets/uploads/`: أيقونات التطبيقات ولقطات الشاشة المرفوعة من لوحة الهاتف.
- `apps/`: ملفات APK ووحدة Magisk وملف `manifest.json` وبصمات `SHA256SUMS.txt`.

## رفع تطبيق من الهاتف

افتح `https://ehea1973com-star.github.io/admin.html` من متصفح الهاتف.

- أنشئ GitHub Fine-grained Token بصلاحية `Contents: Read and write` على هذا المستودع فقط.
- أدخل اسم التطبيق واسم الحزمة والإصدار والقسم وملف APK.
- يمكن رفع أيقونة واختيار حتى 3 لقطات شاشة (كل لقطة حتى 1 MB).
- تُرفع الملفات إلى `apps/`، ويُحدّث `apps/manifest.json` و`apps/SHA256SUMS.txt` تلقائيًا.
- تظهر التطبيقات المرفوعة في الصفحة الرئيسية بعد نشر GitHub Pages، مع البحث والتصفية وفتح التفاصيل والمشاركة.
- الحد الحالي 25 MB لكل ملف؛ الملفات الأكبر تُرفع عبر GitHub Releases.
- لا تُحفظ صلاحيات GitHub داخل الموقع؛ التوكن اختياري الحفظ على جهازك فقط.
- رابط المشاركة العميق `?app=<package>` يفتح تفاصيل التطبيق مباشرة.

## ملاحظات

- لا تُرفع ملفات keystore أو كلمات المرور إلى المستودع.
- حد GitHub لملف واحد هو 100 MB.
- التطبيقات الثلاثة الجديدة موقعة بنفس التوقيع، ورقم `versionCode` الحالي هو `2`؛ يجب رفعه في التحديث القادم.
- وحدة Magisk مخصصة للأجهزة التي تدعم Magisk أو ROM مخصصًا.
- المتصفحات تمنع تشغيل الصوت تلقائيًا قبل تفاعل المستخدم؛ يبدأ الموقع محاولة التشغيل تلقائيًا، ثم يبدأ الموسيقى عند أول لمسة أو ضغطة مفتاح.
- قسم البث المباشر يستخدم قناة يوتيوب `UCmChpVHGV74adiqncSyocg`، ويظهر البث عند بدء البث المباشر من القناة.
