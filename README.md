# Yahya Tech — الموقع الرسمي

الموقع الرسمي ليحيى الحمزة — Yahya Tech، منشور على GitHub Pages:

`https://ehea1973com-star.github.io/`

## المحتويات

- `index.html`: الصفحة الرئيسية، بطاقات التطبيقات وروابط التحميل.
- `download.html`: صفحة تحميل مستقلة لكل تطبيق، مع تسجيل الدخول وزر رجوع سهل للرئيسية.
- `admin.html`: لوحة رفع التطبيقات من الهاتف.
- `404.html`: صفحة الخطأ.
- `assets/style.css`: تنسيق الموقع الكامل والواجهة المتجاوبة.
- `assets/admin.css` و`assets/admin.js`: تنسيق ووظائف لوحة الرفع.
- `assets/script.js`: البحث والتصفية، نافذة تفاصيل التطبيق، المشاركة، الرابط العميق، رفع لقطات الشاشة من نافذة التطبيق، تبديل فيديوهات/بث يوتيوب، ومحرك بحث ويب داخلي عبر Tavily.
- `assets/theme.js`: الوضع الليلي/النهاري مع حفظ الاختيار في المتصفح.
- `assets/auth.js`: مصادقة Firebase عبر البريد وكلمة المرور، وإدارة جلسة المستخدم ونافذة الحساب.
- `assets/firebase-config.js`: إعداد مشروع Firebase (`apiKey` وبقية حقول تطبيق الويب).
- `assets/catalog.js` و`assets/download.js`: بيانات التطبيقات وصفحة التحميل المستقلة.
- `assets/audio.js`: موسيقى هادئة مولّدة داخل المتصفح تتغيّر كل دقيقة، وأصوات الأزرار.
- `assets/logo.svg` و`assets/icons/`: شعار الموقع وأيقونات التطبيقات.
- `assets/uploads/`: أيقونات التطبيقات ولقطات الشاشة المرفوعة من لوحة الهاتف.
- `apps/`: ملفات APK ووحدة Magisk وملف `manifest.json` وبصمات `SHA256SUMS.txt`.

## رفع تطبيق من الهاتف

افتح `https://ehea1973com-star.github.io/admin.html` من متصفح الهاتف.

- أنشئ GitHub Fine-grained Token بصلاحية `Contents: Read and write` على هذا المستودع فقط.
- أدخل اسم التطبيق واسم الحزمة والإصدار والقسم وملف APK.
- يمكن رفع أيقونة واختيار حتى 3 لقطات شاشة (كل لقطة حتى 1 MB).
- بعد حفظ GitHub Token في لوحة الإدارة، يظهر زر «إضافة لقطات شاشة» داخل نافذة تفاصيل التطبيق المرفوع، ويمكن إضافة الصور مباشرة من هناك.
- تُرفع الملفات إلى `apps/`، ويُحدّث `apps/manifest.json` و`apps/SHA256SUMS.txt` تلقائيًا.
- تظهر التطبيقات المرفوعة في الصفحة الرئيسية بعد نشر GitHub Pages، مع البحث والتصفية وفتح التفاصيل والمشاركة.
- الحد الحالي 25 MB لكل ملف؛ الملفات الأكبر تُرفع عبر GitHub Releases.
- لا تُحفظ صلاحيات GitHub داخل الموقع؛ التوكن اختياري الحفظ على جهازك فقط.
- رابط المشاركة العميق `?app=<package>` يفتح تفاصيل التطبيق مباشرة.

## إعداد Firebase Auth

1. افتح `https://console.firebase.google.com/` وأنشئ مشروعًا جديدًا.
2. من `Authentication` > `Sign-in method` فعّل `Email/Password`.
3. من `Project settings` > `General` > `Your apps` أضف تطبيق ويب `</>`.
4. انسخ إعدادات تطبيق الويب إلى `assets/firebase-config.js`، وأهمها `apiKey`.
5. من `Authentication` > `Settings` > `Authorized domains` أضف `ehea1973com-star.github.io`.
6. `apiKey` في Firebase معرف عام لتطبيق الويب وليس سرًا، ولا يمنح صلاحيات إدارية. لا تضع `service account` أو مفاتيح خاصة في الموقع.
7. هذه المصادقة تعمل من GitHub Pages دون خادم؛ Firebase هو من يتحقق من الحساب ويصدر الجلسة.
8. إذا ظهر `CONFIGURATION_NOT_FOUND` فمعناه أن مزوّد `Email/Password` غير مفعّل بعد في `Authentication` > `Sign-in method`.
9. بريد المالك يُضبط في `ownerEmails` داخل `assets/firebase-config.js`؛ صاحب هذا البريد يظهر له «مالك الموقع» ورابط لوحة الإدارة.

## ملاحظات

- لا تُرفع ملفات keystore أو كلمات المرور إلى المستودع.
- حد GitHub لملف واحد هو 100 MB.
- التطبيقات الثلاثة الجديدة موقعة بنفس التوقيع، ورقم `versionCode` الحالي هو `2`؛ يجب رفعه في التحديث القادم.
- وحدة Magisk مخصصة للأجهزة التي تدعم Magisk أو ROM مخصصًا.
- المتصفحات تمنع تشغيل الصوت تلقائيًا قبل تفاعل المستخدم؛ يبدأ الموقع محاولة التشغيل تلقائيًا، ثم يبدأ الموسيقى عند أول لمسة أو ضغطة مفتاح.
- قسم يوتيوب يعرض آخر فيديوهات القناة `UCmChpVHGV74adiyqncSyocg` افتراضيًا، مع تبويب «البث المباشر» الذي يعمل عند بدء البث من القناة.
- محرك البحث الداخلي يستخدم Tavily Search في وضع keyless (بدون مفتاح وبدون Google)، ويعرض النتائج داخل الموقع مع إمكانية قراءة نص الصفحة عبر Tavily Extract دون مغادرة الموقع.
- تسجيل الدخول يتم عبر Firebase Authentication، ويُحفظ رمز الجلسة في `localStorage` لتجنب تسجيل الدخول عند كل زيارة. زر التحميل يفتح `download.html?app=<id>` ويطلب تسجيل الدخول قبل إظهار رابط التحميل.
- بوابة التحميل واجهة فقط؛ Firebase يتحقق من الحساب، لكن ملفات APK المباشرة تبقى قابلة للوصول إذا عُرف رابطها.
- صفحة التحميل تعرض بيانات التطبيق، وتتيح الرجوع إلى الصفحة الرئيسية من أعلى الصفحة وأسفلها. فتح `download.html` بدون `?app=` يعرض قائمة بكل التطبيقات.
